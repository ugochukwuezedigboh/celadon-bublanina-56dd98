# Integrated Aviation AI Dashboard

## Overview
This project is a **Capstone initiative** for Aviation Safety, Airspace & Weather Intelligence in Nigeria. It integrates AI capabilities across **NiMet**, **NAMA**, and **FAAN** into a single **Common Operating Picture**.

## Problem
Air travellers, airlines, and airspace users face preventable weather-related delays and diversions because NiMet, NAMA, and FAAN operate on siloed, manual systems without a shared real-time intelligence layer.

## Solution
- **NiMet**: Severe-weather nowcasting (0–6hr prediction).
- **NAMA**: Automated flight-path-matched weather alerting.
- **FAAN**: Terminal congestion forecasting and passenger flow prediction.
- **Shared Layer**: Real-time dashboard for synchronized decision-making.

## Features
- Predictive weather intelligence (NiMet).
- Automated ATC alerts (NAMA).
- Passenger flow and gate adjustment forecasting (FAAN).
- KPI-driven dashboard with measurable outcomes.
